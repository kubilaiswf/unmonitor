## Restricted capability: runFullTrust

> Unmonitor is a Win32 tray utility for people who get HDMI audio from an AV receiver or soundbar, which Windows also treats as a display. It needs full trust to keep the mouse off that display with a low-level mouse hook, move other apps' windows off it, change its resolution, and keep an audio stream open on the HDMI audio device. It has no network access and collects no data.

## Description (English)

When a receiver or soundbar is connected to a PC over HDMI, Windows treats it as a second display. Turning that display off also turns off the audio. Leaving it on means the mouse and windows keep disappearing onto a screen you can't see.

Unmonitor leaves the display enabled, so audio keeps working, and makes Windows behave as if it weren't there. Pick your receiver or soundbar once from the tray menu.

- Lock mouse: the cursor stops at the edge of your real monitors.
- Move windows back: windows that end up on the speaker's screen come back to the monitor you are using.
- Keep audio awake: stops the receiver from dropping the HDMI audio link, which cuts off the start of sounds.
- Run hidden screen at 720p: the GPU doesn't draw an invisible 4K desktop.
- Start with Windows.

Free for personal use. Source code: https://github.com/kubilaiswf/unmonitor
